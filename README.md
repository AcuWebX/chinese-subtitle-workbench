# 中文字幕工作台

一个在 Windows 本机运行的中文字幕视频处理工具：拖入一个或多个视频，自动识别对白、翻译成中文并生成带中文字幕的视频副本。视频和任务数据只在本机处理。

## 使用

1. 双击 `DEPLOY.cmd`，选择模型和缓存保存位置，等待部署完成。
2. 双击 `START.cmd`，程序会等待服务就绪后自动打开本地工作台。
3. 选择输出文件夹，然后一次拖入一个或多个视频。

`START.cmd` 打开的黑色 CMD 窗口是后台服务，处理期间不能关闭；全部任务完成后再关闭。若浏览器没有自动打开，请访问 `http://127.0.0.1:8766/`。

视频只在本机处理，不上传到 GitHub 或 ChatGPT。首次部署会安装依赖并下载语音识别模型，之后启动和处理会更快。网页中的“清理任务缓存”只删除本地上传缓存，不删除已生成的视频或模型。

## 依赖

- Windows 10/11
- Python 3.11+
- FFmpeg
- `faster-whisper` 和 `deep-translator`（由部署脚本安装）

## 隐私

上传缓存、模型、临时文件和输出目录已加入 `.gitignore`，不要将个人视频或生成文件提交到仓库。
